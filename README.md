# AI 员工管理系统（半导体初创 · v2）

> 基于 `ai-payroll` MVP 重构扩展：参考 [Frappe HR](https://github.com/frappe/hrms) 的模块化设计，面向 **30-150 人 Fabless/IDM/设备材料初创**，重点突出 **招聘管理** 与 **薪酬成本管理**。
> 架构设计见 [`NEW-ARCHITECTURE.md`](NEW-ARCHITECTURE.md)；产品设计见 [`ai-compensation-product-design.md`](ai-compensation-product-design.md)。

## 模块一览

| 模块 | 页面 | 说明 |
|---|---|---|
| 📊 工作台 | `/` dashboard | 员工/招聘/成本一屏总览 + 重点模块入口 |
| 🎯 招聘管理 ⭐ | 招聘总览 · 候选人管线 · 招聘需求 · 面试记录 · 渠道与成本 | 半导体岗位漏斗/周期/人均招聘成本；Kanban 阶段流转；Offer 定薪建议（引用对标带宽）；**Offer → 入职自动生成员工档案** |
| 👥 员工管理 | 员工档案 · **员工完整档案** · 组织架构 | 档案 CRUD + 部门归属 + 入转调离事件流；**完整档案页**（基本信息/联系方式/紧急联系人/教育经历/工作经历/家庭/合同社保/银行/技能）；部门树 + 编制 vs 实际 |
| 🧮 薪酬与期权 | 算薪工作台 · 对标与带宽 · 期权模拟 · 员工薪酬单 | 累计预扣法算薪、对标 P25/P50/P75、期权估值（保留自 MVP） |
| 💰 薪酬成本 ⭐ | 成本总览 · 预算对比 · 成本预测 | 公司口径成本（应发+公司社保26%+公积金7%+期权摊销）；预算 vs 实际；编制计划→6 个月成本预测 |
| ✅ 审批中心 / 💬 AI 助手 / ⚙️ 设置 | — | 审批流；RAG+KB 问答（含招聘/成本知识） |

## 技术栈

- **后端**：Node.js ≥ 22（内置 `node:sqlite`，零原生依赖）+ Express，SQLite 数据库 `payroll.db`
- **前端**：React 18 + Vite（无 UI 框架依赖，手写样式）
- **权限**：token 会话（12h），角色 founder / hr / emp

## 运行


## 演示路径（10 分钟）

1. **工作台** → 重点模块入口 → **候选人管线**（看板：新简历→初筛→面试→Offer→已入职）
2. 打开 Offer 阶段候选人 → 看 **定薪建议**（带宽 P25/P50/P75 + 分位）→ 点 **🚀 办理入职** → 员工档案自动生成 + 入职事件自动记录 + 需求满编自动关闭
3. **招聘总览** → 漏斗/平均周期（47 天）/人均招聘成本（¥17.8 万）
4. **成本总览** → 公司口径成本 ¥64.9 万（6 月）、部门×类别构成、环比归因
5. **预算对比** → 预算 vs 实际（红色=超预算）；**成本预测** → 编制计划→未来 6 个月成本曲线（可新增/删除编制，预测即时联动）
6. **员工档案** → 点任意员工「档案」进入完整档案页：基本信息（性别/生日/婚姻/民族/学历/证件）、联系方式（手机/邮箱/地址）、紧急联系人、教育经历、工作经历、家庭信息、合同与社保（合同期限/转正日期/社保号/公积金号/银行卡/技能）
7. **简历与 AI 解析**（员工档案页底部）→ 上传简历（txt/md/docx/pdf）→ 点「🤖 AI 解析」→ 预览提取结果 → 「✅ 应用到档案」一键填充基本信息/教育/工作经历；简历作为附件保留，可下载/删除

## 公司薪酬成本口径

```
公司月度成本 = 应发工资(base+perf+ot)
            + 公司社保(缴费基数×26%≈养老16+医疗9.5+失业0.5+工伤0.2)
            + 公司公积金(缴费基数×7%)
            + 期权摊销(年度期权价值÷12)      # 员工 annual_option_value
            + 招聘摊销(渠道费用按入职月份计入)  # 成本总览-招聘成本
```

预算按 `部门 × 成本类别(salary/social/fund/option/recruiting/other)` 维护（`cost_budgets` 表）；预测按 `headcount_plan`（部门×月份×编制）聚合到顶层部门 × 人均成本。
