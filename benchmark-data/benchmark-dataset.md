# 历史对标推导样例与质量验证

> 配套文件：`benchmark-dataset.json`（2025 年形成的公开资料推导样例，默认 `verified:false`）
> 验证脚本：`validate_benchmark.py` → 输出 `validation-report.md`（当前结果：**13 条 / 0 FAIL / 5 WARN**）
>
> 重要：这些分位含人工推导，来源正文和样本口径未在仓库内完成复核，不能直接用于定薪。生产带宽必须从同城市、同经验段、同公司类型的原始样本生成，并完成制单人与审批人分离的审批。

## 1. 历史资料线索（不等于已核验成交数据）

| 数据源类型 | 说明 | 历史样例使用情况 |
|---|---|---|
| 行业薪酬报告 | 锐仕方达《2024 半导体行业薪酬报告》、中智咨询《2024 高科技行业薪酬调研》 | 报告索引 + 新闻转述（付费全文待采购） |
| 行业白皮书/洞察报告 | 《集成电路行业人才洞察报告 2024》（媒体转述） | ✅ 关键趋势依据 |
| 政府指导价 | 各地人社局工资指导价位 | 待补充（城市系数校准用） |
| 招聘平台公开岗位 | 猎聘岗位薪资（50-80K·14-16 薪等） | ✅ 岗位级信号 |
| 行业媒体 | EEFOCUS、今日头条榜单等 | ✅ 交叉验证 |

**注意**：报告均值、招聘报价、上市公司人均薪酬与实际成交分位不是同一口径。`evidence` 只是历史资料数量标签，不代表内容已经被人工核验。

## 2. 历史推导记录（不是当前市场结论）

| 方向 | 当时收集的公开线索 | 原型 P50 | 样例 P50 | 当时的推导 |
|---|---|---|---|---|
| 模拟IC设计 | 应届 33-46万、资深 45-75万、猎聘洞察 40-50万、2024 下滑 | 58万 | **50万** | ⬇️ 原型偏高 10-20% |
| 数字前端 | 脉脉均值 81万（全经验招聘口径）、猎聘洞察 40-50万 | 52万 | 52万 | ✅ 合理 |
| 数字验证 | 榜单破 50万、拉勾高端 65-90万 | 48万 | 50万 | ⬆️ 微调 |
| 数字后端 | 2024 回落、无聚合数字 | 55万 | 50万 | ⬇️ 下调 |
| 版图设计 | 无公开数字 | 38万 | 38万 | ✅（弱证据） |
| 工艺工程师 | **工艺+设备平均仅约 20万/年（+7~8%）**；中芯研发 53万（高端锚） | 45万 | **36万** | ⬇️ 原型明显高估（未区分全经验平均口径） |
| 设备工程师 | 同工艺（正增长但均值低） | 40万 | **32万** | ⬇️ 明显高估 |
| EDA研发 | 概伦研发平均 42.9万、资深 70-130万 | 60万 | 50万 | ⬇️ 略偏高 |
| 芯片测试 | 应届 28-42万、2024 下降 | 42万 | 40万 | ⬇️ 微调 |
| 封装工程师 | 长电人均 19-22万（含生产人员） | 44万 | **36万** | ⬇️ 明显高估（需拆传统/先进封装） |
| 器件/固件 | 无公开数字 | 48/40万 | 45/38万 | ✅（弱证据） |

**当时采用的假设（现均需重新验证）**：
1. **原型对模拟IC 高估 10-20%**（58万→50万），电源/高速接口+15薪高端仍可达 60-70万；
2. **原型对工艺/设备/封装明显高估**——洞察报告 2024 显示工艺+设备全经验平均仅约 20万/年，长电人均 19-22万；
3. **2024 分化**：工艺/设备↑、模拟/数字前后端/测试/软件↓——趋势标注需修正；
4. **招聘开价高于实发 10-20%**（脉脉/拉勾/猎聘口径），本数据集已按此下修；
5. **城市数据严重不足**：不同城市不可用固定系数外推，应补充同口径原始样本。

## 3. 数据质量验证体系（validate_benchmark.py）

```
S1 结构完整性    必填字段、类型
S2 数值一致性    P25<=P50<=P75、正数、年终薪数 [12,18]
S3 行业合理性    方向家族合理区间（PLAUSIBLE 表，可维护）
S4 来源强度      证据强度(强=3源/中=2源/弱=1源) 与 URL 合法性
S5 覆盖度        与目标方向清单对比（当前 11/11 全覆盖）
S6 稀缺性排序    稀缺系数单调性（EDA>模拟>工艺>数字后端>验证/前端>封装/器件>测试/固件/版图）
```

**当前结果**：13 条记录，0 FAIL / 5 WARN。它只说明 JSON 结构和基础数值关系通过；5 条记录仍缺少可复核的数字锚点，全部记录都必须人工核验后才能进入生产审批。

## 4. 遗留缺口与下一步

1. **城市样本**：按城市独立采样，不使用“上海=1.0”的固定城市系数；
2. **第三方报告锚点**：EDA/封装/器件/版图弱证据方向，建议按需采购 1-2 份关键岗位报告；
3. **趋势字段**：只有来源明确、有效期明确的序列数据才生成趋势；
4. **经验段**：各经验段独立采样，不用固定经验系数外推；
5. **成交价校准**：自家真实发放数据回流（自建系统独有优势），逐月替换招聘报价信号。

## 5. 与抓取管线的衔接

```
未来经合规评审的数据导入：公开或授权数据 → 原始岗位级样本
     ↓ 交叉校准
历史样例（benchmark-dataset.json）：仅用于验证导入和审批链路，不作为生产锚点
     ↓ 输出
已审批对标库：同口径 P25/P50/P75 + 原始来源 + 审批留痕
```
